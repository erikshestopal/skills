# Chat answers

The user reads the answer in a terminal and wants the picture first.

## Shape

1. The answer or the result, in the first sentence.
2. One visual: a snippet, a bordered table, a before/after, or a merman diagram.
3. A few one-line bullets for what the visual can't carry: implications, next steps, or what you didn't check.

Make the shortest answer that is complete. Answer only what was asked, and leave out adjacent topics. The user asks for depth when they want it.

## Rules

- When the user has been away from the problem, give the context in one or two sentences before the result.
- Draw tables with borders (`+---+`). Draw a timeline as a bordered table with one event in each row and columns for time, event, and resulting state.
- Back every claim with evidence the user can inspect, or leave the claim out.
- For a decision, use the shape in `reply.md`: context, question, what each answer changes.
- End on the last real point. A closing offer or recap adds nothing.
